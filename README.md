# uweb.by — лендинг разработки сайтов

Адаптивный русскоязычный лендинг на HTML, CSS и JavaScript с Vite. Светлая
голубая и лавандовая палитра, фото Евгения на первом экране, тёмно-синий прайс,
этапы работы, блок передачи сайта, отзывы, FAQ и форма с отправкой заявки на почту. Кириллический шрифт хранится
локально; внешние сервисы для отображения страницы не нужны.

## Скачать готовый сайт

[forma-site.zip](./forma-site.zip) — готовая сборка для хостинга. Откройте файл
на GitHub и нажмите **Download raw file**. Распакуйте ZIP и загрузите всё
содержимое в корневую папку сайта на хостинге. Инструкция находится внутри архива.

Для получения исходников выберите **Code → Download ZIP** на странице
репозитория или клонируйте его через Git.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (рекомендуется Node.js 24).
Откройте терминал в папке проекта и выполните:

```sh
npm ci
npm run dev
```

В облачной среде используйте существующий checkout `/workspace/plugins`.
Облачные задачи уже изолированы; дополнительный Git worktree не требуется.
Если домашний каталог недоступен для записи, используйте
`npm ci --cache /tmp/forma-npm-cache`. После перезапуска среды сервер нужно
запустить снова.

## Сборка и публикация

```sh
npm run build
npm run preview -- --port 4173
```

`dist/` — готовый сайт. Разместите содержимое каталога в корне сайта на хостинге
с PHP 8.2+ и настроенной функцией `mail()`. Обработчик `send-mail.php` уже включён
в сборку и ZIP; Node.js на хостинге не нужен. Сборка не требует секретов и базы данных.
При изменении сайта пересоберите также архив `forma-site.zip`, чтобы он
соответствовал обновлённой версии.

## Цены и контакты

Цены в `index.html`: лендинг от 400 BYN, сайт компании от 700 BYN,
интернет-магазин от 900 BYN. Индивидуальный проект обсуждается отдельно.

- Email: `sitehub24@gmail.com`.
- Telegram: `https://t.me/develop_by`.
- Телефон: `+375255032030`.

Форма отправляет заявку без всплывающего окна и почтового приложения.
Во время отправки кнопка блокируется; результат появляется прямо под формой.
При ошибке заполненные поля сохраняются, при успешной отправке — очищаются.

Получатель `sitehub24@gmail.com` и отправитель `info@uweb.by` зафиксированы на сервере
в `public/send-mail.php`. Письмо содержит формат сайта, имя, контакт и описание
проекта. Если посетитель указал email, он попадает в `Reply-To`, чтобы удобно
ответить клиенту. Адрес обработчика задаётся в `src/config.js`, видимые контактные
ссылки — в `index.html`. Не помещайте пароли или API-ключи в клиентский код.

Обработчик проверяет поля, размер запроса и источник, игнорирует скрытое поле для
ботов и ограничивает число отправок: 5 за 10 минут с одного IP и 60 за 10 минут
всего. Временный каталог PHP должен быть доступен для записи. Лимиты не содержат
текстов заявок и сохраняют только хеши IP и короткие списки временных меток.
Без JavaScript форма отправляется обычным POST и показывает отдельную страницу
с результатом.

Vite обслуживает только клиентскую часть и не исполняет PHP. Для проверки полной
сборки локально используйте PHP:

```sh
npm run build
php -S 127.0.0.1:8000 -t dist
```

Для доставки писем на хостинге должна быть настроена `mail()` с отправителем
`info@uweb.by`. Успех обработчика означает, что почтовая система приняла письмо;
реальную доставку на Gmail проверьте после загрузки сайта на хостинг.

Бренд сайта — `uweb.by`. Оригинальное фото разработчика хранится в
`public/images/developer.png`; в готовой сборке оно находится в `images/`.
Первый экран представляет Евгения и подчёркивает личную ответственность за
проект. Фото отображается без обрезки лица; мягкие края объединяют его с фоном.
Основной текст — 16–18 px, небольшие подписи — не менее 14 px. На первом экране
предложение «Сайт для бизнеса, который помогает продавать», одна основная
кнопка. На фоне движутся орбитальные маркеры, небольшое окно браузера, курсор,
декоративные элементы и голубые и лавандовые свечения. Цены находятся в
разделе тарифов. Анимации учитывают системную настройку уменьшения движения.
Тарифы раскрываются по нажатию; кнопка внутри описания выбирает услугу в форме.
Кнопка отправки формы занимает ширину своего содержимого.

Прокрутка колесом мыши плавно сглаживается с помощью Lenis. На устройствах с
сенсорным управлением и при системной настройке уменьшения движения сохраняется
обычная прокрутка браузера.

В секции отзывов опубликованы 10 текстов, имён и оценок, предоставленных владельцем
сайта. На компьютере и планшете одновременно видны две карточки отзывов,
на телефоне — одна. Кнопки и стрелки клавиатуры переключают отзывы по две
карточки на широком экране и по одной на телефоне. Доступен горизонтальный свайп;
автоматического перелистывания нет. Без JavaScript лента остаётся прокручиваемой.
Отзывы хранятся непосредственно в `index.html`; после добавления или удаления
отзыва обновите общее число в `.review-counter`.

Синяя кнопка в правом нижнем углу раскрывает ссылки на Telegram и звонок. Её можно
закрыть повторным нажатием, кликом вне блока или клавишей Escape. Раскрытие
и контактные ссылки работают также без JavaScript.

## Проверка изменений

Проверки PHP-обработчика требуют PHP CLI и Python 3:

```sh
php -l public/send-mail.php
python3 -m unittest discover -s tests -v
```

Тесты используют настоящий PHP-обработчик с локальным перехватом `mail()`:
они проверяют адреса и содержание писем, ошибки, защиту заголовков и параллельные
лимиты отправки. Письма в интернет при тестировании не отправляются.

Перед публикацией выполните `npm run build`. В браузере проверьте мобильное меню,
выбор услуги из прайса, отправку формы и результат под кнопкой. Не отправляйте тестовые
заявки без необходимости. Проверенная версия не имеет горизонтальной прокрутки
на ширинах 320, 360, 390, 650, 768, 900, 1024 и 1440 px.

в `public/fonts/OFL.txt`. Lenis распространяется по MIT; лицензия сохранена в
