# uweb.by — разработка сайтов, SEO и контекстная реклама

Три адаптивные русскоязычные страницы на HTML, CSS и JavaScript с Vite:
`/` — разработка сайтов, `/seo/` — поисковое продвижение, `/ppc/` — контекстная реклама. Общая голубая
и лавандовая палитра, тёмно-синий прайс, этапы работы, отзывы, FAQ и формы
с отправкой на почту. Шрифты и скрипты хранятся локально.

Исходники страниц — `index.html`, `seo/index.html` и `ppc/index.html`. Vite собирает все три страницы
в `dist/`; между услугами можно перейти по ссылкам в подвале.

## Скачать готовый сайт

[forma-site.zip](./forma-site.zip) — готовая сборка для хостинга. Откройте файл
на GitHub и нажмите **Download raw file**. Распакуйте ZIP и загрузите всё
содержимое в корневую папку сайта на хостинге. Инструкция находится внутри архива.

Для получения исходников выберите **Code → Download ZIP** на странице
репозитория или клонируйте его через Git.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (рекомендуется Node.js 24).
Откройте терминал в папке проекта и выполните:

```sh
npm ci
npm run dev
```

В облачной среде используйте существующий checkout `/workspace/plugins`.
Облачные задачи уже изолированы; дополнительный Git worktree не требуется.
Если домашний каталог недоступен для записи, используйте
`npm ci --cache /tmp/forma-npm-cache`. После перезапуска среды сервер нужно
запустить снова.

## Сборка и публикация

```sh
npm run build
npm run preview -- --port 4173
```

`dist/` — готовый сайт с тремя страницами. Разместите всё содержимое каталога
в корне сайта на хостинге, включая папки `seo/`, `ppc/`, общие ресурсы и `send-mail.php`.
Нужен PHP 8.2+ с настроенной функцией `mail()`. Обработчик `send-mail.php` уже включён
в сборку и ZIP; Node.js на хостинге не нужен. Сборка не требует секретов и базы данных.
При изменении сайта пересоберите также архив `forma-site.zip`, чтобы он
соответствовал обновлённой версии.

Форма отправляет заявку без всплывающего окна и почтового приложения.
Во время отправки кнопка блокируется; результат появляется прямо под формой.
При ошибке заполненные поля сохраняются, при успешной отправке — очищаются.

Получатель `sitehub24@gmail.com` и отправитель `info@uweb.by` зафиксированы на сервере
в `public/send-mail.php`. Письмо содержит выбранную услугу, имя, контакт и описание
проекта. SEO-заявка имеет отдельную тему «Заявка на SEO — uweb.by»
и необязательное поле адреса сайта. PPC-заявки получают тему «Заявка на PPC — uweb.by»
и выбранный тариф. Этот адрес включается только в письмо:
сервер не обращается к нему. Если посетитель указал email, он попадает в `Reply-To`, чтобы удобно
ответить клиенту. Адрес обработчика задаётся в `src/config.js`, видимые контактные
ссылки — в HTML каждой страницы. Не помещайте пароли или API-ключи в клиентский код.

Обработчик проверяет поля, размер запроса и источник, игнорирует скрытое поле для
ботов и ограничивает число отправок: 5 за 10 минут с одного IP и 60 за 10 минут
всего. Временный каталог PHP должен быть доступен для записи. Лимиты не содержат
текстов заявок и сохраняют только хеши IP и короткие списки временных меток.
Без JavaScript форма отправляется обычным POST и показывает отдельную страницу
с результатом.

Vite обслуживает только клиентскую часть и не исполняет PHP. Для проверки полной
сборки локально используйте PHP:

```sh
npm run build
php -S 127.0.0.1:8000 -t dist
```

Для доставки писем на хостинге должна быть настроена `mail()` с отправителем
`info@uweb.by`. Успех обработчика означает, что почтовая система приняла письмо;
реальную доставку на Gmail проверьте после загрузки сайта на хостинг.

и контактные ссылки работают также без JavaScript.

## Проверка изменений

Проверки PHP-обработчика требуют PHP CLI и Python 3:

```sh
php -l public/send-mail.php
python3 -m unittest discover -s tests -v
```

Тесты используют настоящий PHP-обработчик с локальным перехватом `mail()`:
13 тестов проверяют адреса и содержание писем трёх страниц, SEO-форматы, PPC-тарифы
и адрес сайта, ошибки, защиту заголовков и параллельные
лимиты отправки. Письма в интернет при тестировании не отправляются.

Перед публикацией выполните `npm run build`. В браузере проверьте мобильное меню,
выбор услуги из прайса, отправку формы и результат под кнопкой. Не отправляйте тестовые
заявки без необходимости. Проверенная версия не имеет горизонтальной прокрутки
на ширинах 320, 360, 390, 650, 768, 900, 1024 и 1440 px.
