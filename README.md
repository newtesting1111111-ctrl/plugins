# Готовый лендинг для хостинга

Скачайте **[forma-site.zip](./forma-site.zip)** и распакуйте его содержимое в корень тестового домена. Ничего собирать не нужно.

Требуются PHP 8.2+ и настроенная `mail()`. Инструкция — в `READ-ME.txt`.

В корне репозитория также лежат готовые файлы сайта. Исходники разработки сохранены в истории Git до этой очистки.
