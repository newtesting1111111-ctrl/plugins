# uweb.by — лендинг разработки сайтов

Адаптивный русскоязычный лендинг на HTML, CSS и JavaScript с Vite. Светлая
голубая и лавандовая палитра, фото Евгения на первом экране, тёмно-синий прайс,
этапы работы, блок передачи сайта, отзывы, FAQ и форма для подготовки заявки. Кириллический шрифт хранится
локально; внешние сервисы для отображения страницы не нужны.

## Скачать готовый сайт

[forma-site.zip](./forma-site.zip) — готовая сборка для хостинга. Откройте файл
на GitHub и нажмите **Download raw file**. Распакуйте ZIP и загрузите всё
содержимое в корневую папку сайта на хостинге. Инструкция находится внутри архива.

Для получения исходников выберите **Code → Download ZIP** на странице
репозитория или клонируйте его через Git.

## Запуск

Требуется Node.js 20.19+ или 22.12+ (рекомендуется Node.js 24).
Откройте терминал в папке проекта и выполните:

```sh
npm ci
npm run dev
```

В облачной среде используйте существующий checkout `/workspace/plugins`.
Облачные задачи уже изолированы; дополнительный Git worktree не требуется.
Если домашний каталог недоступен для записи, используйте
`npm ci --cache /tmp/forma-npm-cache`. После перезапуска среды сервер нужно
запустить снова.

## Сборка и публикация

```sh
npm run build
npm run preview -- --port 4173
```

`dist/` — готовый статический сайт. Разместите содержимое каталога в корне
сайта на статическом хостинге. Сборка не требует секретов и серверной базы данных.
При изменении сайта пересоберите также архив `forma-site.zip`, чтобы он
соответствовал обновлённой версии.

Получатель письма задаётся в `src/config.js`; видимые контактные ссылки —
в `index.html`. Не помещайте пароли или API-ключи в клиентский код.

Форма проверяет обязательные поля, собирает бриф и открывает готовое письмо
в почтовом приложении через `mailto:`. Посетитель самостоятельно отправляет
письмо. Бриф можно скопировать или скачать как `.txt`. Серверная автоматическая
доставка писем не подключена. Telegram и телефон доступны напрямую.

Бренд сайта — `uweb.by`. Оригинальное фото разработчика хранится в
`public/images/developer.png`; в готовой сборке оно находится в `images/`.
Первый экран представляет Евгения и подчёркивает личную ответственность за
проект. Фото отображается без обрезки лица; мягкие края объединяют его с фоном.
Основной текст — 16–18 px, небольшие подписи — не менее 14 px. На первом экране
предложение «Сайт для бизнеса, который помогает продавать», одна основная
кнопка. На фоне движутся орбитальные маркеры, небольшое окно браузера, курсор,
декоративные элементы и голубые и лавандовые свечения. Цены находятся в
разделе тарифов. Анимации учитывают системную настройку уменьшения движения.
Тарифы раскрываются по нажатию; кнопка внутри описания выбирает услугу в форме.
Кнопка отправки формы занимает ширину своего содержимого.

Прокрутка колесом мыши плавно сглаживается с помощью Lenis. На устройствах с
сенсорным управлением и при системной настройке уменьшения движения сохраняется
обычная прокрутка браузера. Открытие окна брифа останавливает прокрутку фона.

В секции отзывов опубликованы 10 текстов, имён и оценок, предоставленных владельцем
сайта. Переключение — кнопками, стрелками клавиатуры и горизонтальным свайпом;
автоматического перелистывания нет. Без JavaScript лента остаётся прокручиваемой.
Отзывы хранятся непосредственно в `index.html`; после добавления или удаления
отзыва обновите общее число в `.review-counter`.

Синяя кнопка в правом нижнем углу раскрывает ссылки на Telegram и звонок. Её можно
закрыть повторным нажатием, кликом вне блока или клавишей Escape. Раскрытие
и контактные ссылки работают также без JavaScript.

## Проверка изменений

Перед публикацией выполните `npm run build`. В браузере проверьте мобильное меню,
выбор услуги из прайса, заполнение формы и адрес письма. Не отправляйте тестовые
заявки без необходимости. Проверенная версия не имеет горизонтальной прокрутки
на ширинах 320, 360, 390, 650, 768, 900, 1024 и 1440 px.

Шрифт Golos Text распространяется по SIL Open Font License; лицензия сохранена
в `public/fonts/OFL.txt`. Lenis распространяется по MIT; лицензия сохранена в
`public/licenses/lenis-MIT.txt`.
